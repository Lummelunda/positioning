# Worked examples and outputs

This index lists the company-specific outputs in this folder. To run the method on a new company, start with the [README](README.md) and its linked definition and prompts. The documents below are readings of particular source material at the stated analysis dates, not reusable instructions or verified buyer research.

| Example | First-pass analysis | Quality assessment | What it illustrates |
|---|---|---|---|

## Working offer note

- [Scaleout offer framing: two buyer entry points](SCALEOUT_OFFER_FRAMING_WORKING_NOTE.md) — a product and positioning hypothesis developed from the discussion. It proposes mission applications and model operations as entry points, with federated learning relevant when the buyer's situation calls for it. The narrower delivery scopes still need internal validation.

**Reading order for a specific company:** analysis → quality assessment → comparison for a defined buyer decision. Read the working offer note as a hypothesis to test, not as a finding established by the website analyses.
